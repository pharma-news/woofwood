# WOOFWOOD — «Серый лес: последний хутор»

Пиксельное выживание в тёмном лесу: вы — оборотень на краю урочища. Днём обыск,
консервы и хлам; ночью — патрули кордона и ночная осада периметра. Голод, жажда,
кровотечение, фонарь, верстак, торг, ловушки, схрон, палатка.

**Играть:** https://pharma-news.github.io/woofwood

## Сенсорное управление (телефон и планшет)

- **Джойстик слева** — движение. До упора — бег (тратит выносливость).
- **Тап по экрану** — прицел и атака в точку тапа (удержание — непрерывная атака).
- **АТАКА** (справа) — держать, чтобы бить туда, где смотрит герой.
- **ОБЫск** — держать у ящика; **ХИЛ** — быстрый медик; **ФОНАРЬ**; **ТИХО** — красться; **ЗАРЯД** — перезарядка.
- **РЮКЗак / МЕНЮ** — сверху. Оружие меняется тапом по ячейкам внизу.
- В меню паузы есть переключатель **«СЕНСОР: ВКЛ/ВЫКЛ»** — если нужен клавиатурный режим.

На компьютере: WASD — движение, мышь — прицел, ЛКМ — атака, Shift — бег, C — красться,
R — перезарядка, F — фонарь, E — обыск/взаимодействие, H — хил, Tab — рюкзак, Esc — меню,
1–3 — оружие, M — звук.

## Структура

```
index.html      — разметка, стили, адаптация под мобильные экраны
js/touch.js     — сенсорное управление: джойстик, кнопки, тап-прицел
js/main.js      — игровой цикл, ввод, рендер, сохранение
js/world.js     — генерация урочища, лагерь, контейнеры
js/entities.js  — враги, оружие, стрельба, удары
js/ui.js        — HUD, панели, лут, крафт, торг
js/data.js      — предметы, оружие, улучшения
js/audio.js     — процедурные звуки
js/hero_meta.js — спрайты и мета героя
```

## Локальный запуск

```
git clone https://github.com/pharma-news/woofwood.git
cd woofwood
python -m http.server 8080     # или любой статический сервер
# открыть http://localhost:8080
```

Сохранения лежат в localStorage браузера, игра автосохраняется при уходе со страницы.
